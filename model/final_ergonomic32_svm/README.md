# final_ergonomic32_svm（本番候補）

人体工学の役割で選んだ32列の特徴量と、ガウスSVMを組み合わせた本番候補のモデルです。回転の揺れ（ジャイロの標準偏差）3列は対数で持ちます。31〜32列目はジャイロxの差分のばらつきです。32列は、学習データで求めた固定の定数で前処理関数の中で標準化します。選んだ経緯と根拠は [特徴量とモデルの検証](../../reports/feature-study-ja.md) にあります。

| 項目 | 内容 |
|---|---|
| 前処理関数 | `submission/ergonomic32_svm/Pretreatment_MATLABcontest_Advanced.m`（32列） |
| 手法 | ガウスSVM、1対1、標準化なし（前処理関数で標準化済み）、カーネルスケール 7.9、ボックス制約 10 |
| 学習データ | 学習用2941窓＋拡張8通り（動きの強さ0.8/1.2倍、装着角度10°×2、歩調0.9/1.1倍、雑音0.005×2）＝26469行 |
| 記録単位の交差検証（5回） | 98.26%（標準偏差0.06ポイント、最悪98.20%） |
| テスト201窓 | 197件正解。テスト201窓は特徴量と設定の選択に使っていない |

`trained.mat` には `trainedModel` 構造体が入っています。`trainedModel.predictFcn(X)` に、前処理関数の出力（N×32）を渡すと予測できます。分類学習器で作り直す場合は、上の表と同じ設定を「ガウスSVM」で手入力し、「データを標準化」を「いいえ」にします。前処理関数の標準化の定数は `scripts/feature_study/write_scaling.m` で書き込みます。作り直しの手順は `scripts/feature_study/train_final.m` です。

公式のライブスクリプトで提出ファイルを書き出す前に、前処理関数の目印の間の部分を公式ファイルへ貼り付けます。また、拡張した学習データ（26469行）を分類学習器に渡せるかを確かめます。
