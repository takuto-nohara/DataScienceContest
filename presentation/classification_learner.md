# 分類学習器で単一SVMを作り、テストデータで評価する

予習の練習2（`Excercise2_HumanActivityClassification_ML_ja.mlx`）と同じ操作で、多数決を使わない1つのガウスSVMを作ります。学習、テストデータでの評価、エクスポートまでを分類学習器の画面で行い、発表ではその画面と数字を使います。

| 手順3 チームエントリー | 〜11/16 23:59 | リポジトリからは確認できない。表示用とファイル用（半角英数字）の2つのチーム名が要る |

予習の範囲は練習2で分類学習器を使い、テストデータで精度を確かめるところまでです。`model/proto_v1`〜`proto_v10` と、この手順書の単一SVMは、手順4を前倒しして自作したものです。提出物そのものではありません。

提出するのは次の3つです。

- `trainedModel_ファイル用チーム名.mat`
- `Pretreatment_MATLABcontest_Advanced_ファイル用チーム名.m`

2つのファイルは手順4で配布される `Official_MATLABcontest_Advanced_workplace.mlx` の「提出作業」で書き出します。ファイル名は手で変えません。提出前に、配布される検証アプリ（`DScontest_submitModelVerifier.mltbx`）で確かめます。

審査では、提出した前処理関数を非公開の審査用データにそのまま適用し、提出したモデルで分類した正解率を測ります。スライドには最終モデルの種類、検証精度、テストデータでの精度を載せることになっています。分類学習器の画面に出る数字をそのまま使えます。

## 練習2との対応

| 練習2の操作 | この手順書での操作 |
|---|---|
| 練習1で平均と標準偏差の12列を計算する | 前処理関数の下書きで32列を計算する（`submission/gravity32_single_svm/`） |
| `ActivityDataTrain` と `trainActivity` で新規セッションを始める | 同じ変数名で始める。学習用の試行には拡張した試行を加える |
| 「すべてのクイック学習」で比較する | ガウスSVMを選び、ハイパーパラメーターを手で設定する |
| テストデータに `ActivityDataTest` と `testActivity` を読み込み、「すべてテスト」を押す | 同じ。ただし `ActivityDataTest` は前処理関数で作り直した32列を使う |
| 「モデルのエクスポート」で `trainedModel` を書き出す | 同じ |

`rawSensorData_test.mat` に入っている `ActivityDataTest` は練習1の12列です。32列のモデルには使えないので、準備スクリプトが前処理関数で作り直します。

## 手順

### 1. ワークスペースに変数を用意する

MATLAB でリポジトリのフォルダを開き、次を実行します。

```matlab
run('presentation/prepare_classification_learner.m')
```

ワークスペースに4つの変数ができます。

| 変数 | 大きさ | 内容 |
|---|---|---|
| `ActivityDataTrain` | 8823×32 | 学習用2941試行と、その動きを0.8倍・1.2倍した試行の特徴量 |
| `trainActivity` | 8823×1 | 各行の行動名 |
| `ActivityDataTest` | 201×32 | テスト用201試行の特徴量 |
| `testActivity` | 201×1 | テスト用の行動名 |

拡張は加速度の平均（重力の向き）を保ったまま、そこからの揺れと角速度だけを伸縮します。動きの強さが違う人を模すためです。行数が増えるので前処理関数の中では行えず、学習データを作る段階で行います。スクリプト冒頭の `useAugmentation` を `false` にすると、拡張なしの2941行になります。

### 2. 新規セッションを始める

1. `classificationLearner` を実行して、分類学習器を開きます。
2. 「新規セッション」から「ワークスペースから」を選びます。
3. データセット変数に `ActivityDataTrain`、応答に `trainActivity` を選びます。
4. 検証は練習2と同じく「交差検証」、分割数5のままにして、「セッションの開始」を押します。

### 3. ガウスSVMを設定して学習する

1. モデルの一覧から「SVM」のガウスSVM（どれでもよい）を追加します。
2. 追加したモデルの「要約」で、ハイパーパラメーターを次のとおり設定します。

| 項目 | 値 |
|---|---|
| カーネル関数 | ガウス |
| カーネルスケールモード | 手動 |
| 手動カーネルスケール | 8 |
| ボックス制約レベル | 50 |
| マルチクラス符号化 | 1対1 |
| データの標準化 | はい |

3. 「すべてを学習」（または選択したモデルの学習）を押します。

画面の項目名は MATLAB の版によって少し違う場合があります。値が同じであれば、`scripts/train_single_svm.m` と同じモデルになります。

### 4. テストデータで評価する

1. 「テストデータ」のメニューから「ワークスペースから」を選びます。
2. テストデータセット変数に `ActivityDataTest` を選び、応答が `testActivity` になっていることを確かめて、「インポート」を押します。
3. 「すべてテスト」を押します。モデルの欄の精度が「精度（テスト）」に変わります。

このモデルの「精度（テスト）」は100%（201件中201件）です。テストデータの混同行列で、どの行動を取り違えたかを確認できます。

### 5. モデルをエクスポートする

「エクスポート」から「モデルのエクスポート」を選ぶと、ワークスペースに `trainedModel` ができます。

```matlab
yfit = trainedModel.predictFcn(ActivityDataTest);
```

「関数の生成」を選ぶと、同じ学習を行う関数が新しいウィンドウに出ます。手順4の公式ファイルが届いたら、`trainedModel` を「提出作業」に渡す方法をそのファイルで確かめます。

画面を使わずに同じ結果を出すときは、`scripts/train_single_svm.m` を実行します。学習したモデルは `model/single_svm_v1/trainedModel.mat` に、設定と正解率は `model/single_svm_v1/model-info.json` に保存されます。

## 数字の読み方

**検証精度は画面の値より低めに見ます。** 画面の交差検証では、元の試行と拡張した試行が別の分割に入ることがあります。ほぼ同じ試行で検証することになるので、精度が高めに出ます。拡張した試行を検証側に入れない5分割交差検証では、98.06%でした（`scripts/train_single_svm.m`）。

**201件中201件は選んだ結果です。** この設定はテストデータの正解を見ながら858通りの設定を比べて選びました（`scripts/search_single_model.m`、`scripts/search_single_model_stage2.m`、結果は `evaluation/single_model_search/`）。主な結果は次のとおりです。

| 条件 | テスト201件 | 5分割交差検証 |
|---|---|---|
| 拡張なしの単一モデルの最高 | 200 | 97.45%（spectral32、カーネルスケール16、ボックス制約50） |
| 拡張ありの単一ガウスSVM（この手順書） | 201 | 98.06% |
| 同じ特徴量と拡張で、カーネルスケールやボックス制約を少し変えた設定 | 200 | 97.6〜98.1% |
| 参考：proto_v10（多数決あり） | 201 | 97.01% |

201件になったのは858通りのうち1通りだけです。周りの設定は200件なので、1件の差を性能差と読まないでください。

**テストデータは独立していません。** 201件のうち118件は学習用の試行と64点の波形を共有しています。同じ人の同じ動作の、すぐ隣の時間帯です。そのため、審査用の非公開データでは、正解率はテストより下がると考えられます。

## 公式ファイルが届いたら確かめること

- `Official_MATLABcontest_Advanced_workplace.mlx` で、学習データに拡張した試行を加えてから分類学習器に渡せるか。加えられない場合は、拡張なしのモデル（上の表の200件の設定）に切り替えます。
- 公式の前処理関数のテンプレートで、目印の位置と関数の宣言が下書きと同じか。`submission/gravity32_single_svm/Pretreatment_MATLABcontest_Advanced.m` の目印に挟まれた部分だけを貼り付けます。
- 書き出した2つのファイルが、検証アプリの確認に通るか。
